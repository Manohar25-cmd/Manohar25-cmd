## About Me

I am a software developer and AI/ML builder focused on turning foundational concepts into practical, well-engineered applications. My work spans intelligent systems, mobile and web software, and privacy-respecting tools designed for everyday reliability.

- **Core Focus:** Exploring Artificial Intelligence, Machine Learning, Deep Learning, Data Science, and modern software architecture through hands-on engineering.
- **Product Engineering:** Designing and building mobile and web applications with clean interfaces, local-first workflows, and strong user privacy defaults.
- **Engineering Philosophy:** Learning by building from first principles, experimenting with emerging tools, and iterating toward dependable, real-world software.
- **Collaboration:** Open to collaborating on AI/ML initiatives, open-source software, developer tooling, and mobile application projects.
